# SmartEdu Portal · 智能教育系统（前端平台）

SmartEdu Portal 是基于 **Vue 3 + Vite + Pinia** 构建的现代化智能教育辅助平台。平台融合了 **RAG (检索增强生成) 大模型技术**，使学生能够针对绑定的专业教材进行即时、精准的 AI 提问与知识库检索，同时为教师和管理员提供了全方位的班级工作台与安全审计机制。

系统采用现代简约的视觉界面，支持“真实后端连接”与“离线沙盒模拟（Mock Sandbox）”双模热切换，具备离线演示和本地运行能力。

---

## 核心技术栈

* **核心框架**：`Vue 3.5` (Composition API, `<script setup>`)
* **状态管理**：`Pinia 3.0` (管理用户鉴权与沙盒全局模式)
* **路由管理**：`Vue Router 4.6` (基于角色的守卫拦截，RBAC)
* **构建工具**：`Vite 8.0` + `Rolldown` (模块热更新与构建优化)
* **图标系统**：`@phosphor-icons/web 2.1.2` (Regular 权重，**全量本地化打包集成**，不依赖外部 CDN，保障离线可用性)
* **样式系统**：`Vanilla CSS` (高灵活性，定义了完备的设计 Tokens 与微动画，支持响应式布局)

## 三端核心模块与角色视图

系统内置了完善的**基于角色的访问控制 (RBAC)**，不同角色在登录后会自动引导至专属工作台：

### 1. 在读学生端 (`/student`) — AI 知识问答书库
* **班级看板**：使用 6 位“班级邀请码”申请加入教师名下的班级。
* **AI 问答书库**：调阅已加入班级授权绑定的教材，针对特定教材开启独立的 AI 对话会话。
* **智能检索对话（RAG）**：在对话流中进行流式（SSE）提问，AI 助手将实时检索教材文本子块提供专业严谨的回答。
* **会话管理**：支持新建对话、会话历史列表、一键清理会话及删除特定会话。

### 2. 授课教师端 (`/teacher`) — 班级与教材知识库工作台
* **班级工作台**：一键创建班级并自动生成唯一的 6 位“班级码”，管理加入的学生并执行入班申请审批。
* **教材知识库**：支持上传本地 PDF 格式教材，系统将流式展示解析状态（切片向量化处理）。
* **教材绑定授权**：一键将已解析的教材批量绑定/解绑至名下的授课班级，即时同步学生端问答权限。
* **学生对话审计**：审计名下所有学生与 AI 助手的问答会话列表（支持按学生、班级、教材筛选），展示由 AI 自动提炼的“会话阶段性摘要”，并可直接调阅详细问答历史以掌握学情。

### 3. 系统管理端 (`/admin`) — 安全审计与系统控制中心
* **用户管理控制台** (`/admin`)：
  - **用户总名册**：按角色与状态多重检索过滤系统注册用户。
  - **资质审批**：对注册为教师的账号执行一键资质审核，批准激活执教与教材管理权限。
  - **安全封禁**：对违规账号执行一键账号冻结或解除冻结，防止违规登录。
  - **通知发布器**：支持“全员系统广播”与“定向用户推送”两种模式，即时下发系统通知。
* **内容安全合规审计** (`/admin/content`)：
  - **授权教材审计**：全面监控系统在案的教材清单，对不合规教材一键执行“强制下架”，物理清理 ChromaDB 向量库并向对应教师发送警告通知。
  - **对话流调阅审计**：全局调阅系统中所有问答会话，点击“调阅对话”可直观调阅该会话包含学生、AI、系统警告的所有历史时间线对话流，并可直接封禁或强制删除不合规会话。
* **大模型系统配置** (`/admin/config`)：
  - 支持热修改大语言模型的 API Key、Base URL、Model Name；
  - 动态拖拽调节 RAG 检索返回子块数 (`RAG_TOP_K`) 以及文本语义切片字数上限 (`TEXTBOOK_CHUNK_SIZE`)，修改立即热生效并持久化写入后端。

## 双模运行机制（离线沙盒）

为了便于在无后端网络或演示环境下进行完整功能汇报，系统设计了**沙盒模拟双模引擎**：
* **模式切换**：在顶部导航栏中央，点击 `模拟沙盒 (Mock)` 或 `真实环境 (Live)` 按钮即可无缝切换。
* **沙盒机制**：当开启沙盒模式时，前端的 `src/utils/api.js` 请求工具会进行自动拦截，所有数据（包括用户列表、教材列表、班级绑定关系、审计会话、问答对话流、通知推送）都将 fallback 到前端的高保真**响应式模拟数据集**中运行。
* **互动功能完整**：在沙盒模式下，创建班级、审批加入、上传教材、流式问答、调阅对话历史、账号冻结、大模型参数调整等动作**均可真实产生交互反馈与界面状态变化**，演示效果与真实连接后端无异。

## Windows 本地调试与运行说明

本部分介绍如何在 Windows 系统中快速安装并运行本系统的前端页面，以便老师或开发人员进行测试。

### 1. 软件环境要求
- **Node.js**: 推荐安装 v20.x 左右的 LTS 稳定版（前往 [Node.js 官方网站](https://nodejs.org/) 下载 Windows `.msi` 安装包，双击一路“下一步”安装即可）。
- 安装完成后，可以打开 CMD 或 PowerShell 运行 `node -v` 和 `npm -v` 以验证是否安装成功。

---

### 2. 依赖安装与本地运行

1. **进入前端目录**：打开终端窗口，进入 `app-frontend` 根目录。
2. **安装项目依赖包**：
   ```bash
   npm install
   ```
3. **启动本地服务**：
   ```bash
   npm run dev
   ```
   - 启动成功后，终端会输出本地访问路径（通常为 `http://localhost:5173/`）。
   - 通过浏览器打开该地址，即可体验系统界面。

---

### 3. 联调后端 API 配置 (Live 真实后端模式)

前端默认连接本地 `http://localhost:8000/api/v1` 的后端 API 服务。

如果您在测试时更改了后端端口或运行在局域网其他电脑上，可以在 `app-frontend` 根目录下手动创建一个文件并命名为 **`.env`**，写入以下内容：
```env
# 配置本地测试所需的后端接口根路径
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
```
*（配置完成后需重新启动 `npm run dev` 使其生效）*

### 离线沙盒（Mock）模式测试说明

本系统设计了 **沙盒模拟双模引擎**，以方便老师或评审人员在**不配置后端数据库、Redis 或没有联网大模型密钥**的情况下，依然能快速且完整地体验系统全部业务功能：

1. **双模切换**：在进入系统页面后，点击顶部导航栏中央醒目的 **`模拟沙盒 (Mock)`** 按钮。
2. **离线测试**：
   - 开启沙盒后，前端请求会被拦截，自动降级切换至本地内存模拟的数据集运行。
   - 在该模式下，您可以直接体验：**创建班级、学生申请加入、教师审批通过、上传教材 PDF（流式模拟解析进度）、RAG 大模型流式对话问答（带思考过程与打字速度缓冲）、审计对话、封禁用户、配置大模型参数**等完整业务闭环。
   - 所有操作均会引起真实的界面反馈与状态持久化变化，非常适合离线演示汇报。

---

### 4. 本地静态打包与预览测试

如果您希望测试生产环境打包后的页面加载性能，可以通过以下命令快速编译和预览：
```bash
# 1. 编译并打包压缩静态文件 (生成的 dist 文件夹可直接用于服务器部署)
npm run build

# 2. 本地直接拉起轻量静态托管服务器预览打包效果
npm run preview
```
